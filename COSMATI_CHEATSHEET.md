# Cosmati quick reference

Cosmati's mouse, keys and sections on one sheet, a supplement to the **[Cosmati manual](COSMATI.md)**. A printable
version is [docs/cheatsheet/cosmati-cheatsheet.pdf](docs/cheatsheet/cosmati-cheatsheet.pdf).

**Ctrl** is **Cmd** on a Mac (Ctrl-click stays the right-click there). Click the window first so the keys reach Cosmati. **Shift-drag** and **Alt-drag** are held while you drag.

## Sections (keys 1 to 9)

Top row, the notes: HOME, SCALE, GEN, SHAPE, PIECE. Bottom row, the sound: SOUND, MOD, FX, MIX, SETUP.

| Section | Pages |
|---|---|
| **SCALE** (1) | SCALES, SCL, KEY, CHORD |
| **GEN** (2) | generator, NOTES, ARP, PATTERN, MOTION |
| **SHAPE** (3) | EVOLVE, FORM, TWEAK, LENGTH, TIMING, ENERGY |
| **PIECE** (4) | PIECE, CHAIN, ENTRIES, LANDSCAPE, PATTERNS, SONG |
| **SOUND** (5) | PRESETS (the sound browser), the engine's pages, ENV |
| **MOD** (6) | MODS, MATRIX, LFOs, ORGANIC |
| **FX** (7) | the effects |
| **MIX** (8) | MIXER, PERF |
| **SETUP** (9) | SETTINGS, TEMPO, SYSTEM, MIDI IN, MIDI OUT |
| **HOME** (0), **SAVE** (-), **REC** (=) | as on the FM-1 |

## Getting around

| Do this | And this happens |
|---|---|
| A section button | Its last page; again: the next page, wrapping after the last |
| Right-click a section | Latches the FM-1 button it stands for |
| Footer tab, wheel over the tabs | That page; the wheel turns the pages |
| Sideways scroll | Previous / next page, stopping at the ends |
| **Ctrl+M** | The page map: click any page |
| **Ctrl+B** | The sound browser (the selected track); a track's right-click: SOUNDS... |
| **Shift+Left / Right** | Previous / next section |
| **Up / Down** | Rows of a list (else SELECT) |
| **Shift+Up / Down** | Previous / next track |
| **Left / Right** | ALGORITHM |
| Mouse back / forward | BACK / OK |
| **[**  **]** or **Esc**  **Enter** | BACK / OK |
| **Page Up / Down** | OCT+ / OCT- |
| **Tab** | Tracks 1-4 / 5-8 |
| **F1**, **?** | Help card of the value under the mouse |
| Click away | Closes a list, sheet or card (as BACK) |

## Values

| Do this | And this happens |
|---|---|
| Drag up / down, wheel | Turns the value |
| Double-click | Its default |
| **Shift**-drag, **Shift**-wheel | Fine steps |
| **Ctrl**-click | Type it: "-6dB", "1/8", "saw" (Enter sets, Esc closes) |
| Right-click | HELP, DEFAULT, COPY / PASTE VALUE, RANDOM, TYPE, LOCK |
| Click a boxed choice | The next choice |
| Drag a picture's handle | Envelope corners, filter peak, algorithm operators, ATLAS, CONSTELLATION, MORPH bar |
| Drag the tempo | A BPM a step (double-click: 120); the DAW sets it while playing |
| Knob ring tick / white arc | The setting / where the mods have it now |

## Lists and the sound browser

| Do this | And this happens |
|---|---|
| Wheel on a list | Scrolls a row a notch |
| Click a row | Moves there; drag changes its value |
| Double-click a row | Moves there and OK |
| Click a sound | Hear it (stopped): root, fifth, octave, root |
| Double-click a sound | Keep it (OK); BACK puts the old one back |
| Click the sound count | FIND: type to filter, Enter keeps, Esc clears |
| Drag a sound onto a TRACKS row | Loads it on that track (EXPANDED) |

## Notes and drums

| Do this | And this happens |
|---|---|
| Click a step | A note at the mouse's pitch; again at another height: a chord (up to 4) |
| Drag a note up / down | Re-pitch it; **Shift**: the whole chord |
| Drag across empty steps | Paints a run of notes |
| Drag from a note across steps | Erases the notes it crosses |
| **Alt**-drag across a note | Its length |
| **Alt**-drag up / down | Its velocity |
| Right-click a note | Removes it |
| Drum grid: click, right-click | Toggle a hit, clear it |
| Drum grid: drag, drag a hit up / down | Paint / erase a lane, accent |
| CHORD USER: drag a card, **+**, right-click | Move the root, add a chord, remove it |

## Mod and long form

| Do this | And this happens |
|---|---|
| MATRIX: click a cell | Opens its mod |
| MATRIX: drag a cell onto another | Makes a mod (a free slot), opens MODS |
| MODS: click, drag, double-click | Pick, amount, type |
| PERF: click a MACRO's row | Opens or makes its mod |
| ENTRIES: click a cell | AUTO, IN, OUT, FADE; right-click: AUTO |
| ENTRIES: click / right-click a letter | Sets / clears the column |
| PATTERNS: click a cell | Queues that pattern |
| SONG: click a letter or block | Picks the section / its track |

## Tracks

| Do this | And this happens |
|---|---|
| Click HOME's column, a TRACKS row | Selects the track |
| Double-click it | Its sounds / its EDIT page |
| **Ctrl+C** | Copy the track (shared by every Cosmati) |
| **Ctrl+V** | Paste the track; its mods keep their track numbers |
| **Ctrl+Shift+V** | Paste only the sound |
| **Alt+Up / Down** | Move the track, renumbering every reference |
| Right-click a track | The same, plus MUTATE |
| M, S on a TRACKS row | Mute; solo (stays until clicked again) |

## Mixer

| Do this | And this happens |
|---|---|
| EXPANDED, MIXER | 8 strips on TRACKS; the FM-1 screen is the track's inspector |
| Fader, sends, PAN | Drag or wheel; double-click: default |
| MIXER (FM-1 size): click a word / right-click | Mute / solo |
| F#3 G#3 A#3 C#4 | Mute T1 to T4 |
| F3 G3 A3 B3 (held) | Solo T1 to T4 |
| C4 D4 E4 F4 | ALL, HOLD, FILL, TAP |
| F#4 G#4 A#4 C#5 | Mute T5 to T8 |
| G4 A4 B4 C5 (held) | Solo T5 to T8 |

## Trying things

| Do this | And this happens |
|---|---|
| Right-click > LOCK | A padlock: DICE and MUTATE leave it alone |
| **Ctrl+R** | DICE THE PAGE (up to 40% around the defaults) |
| **Ctrl+Shift+R** | MUTATE the track's sound (up to 8%) |
| PUT BACK | Undoes the last DICE or MUTATE |
| **A**, **B** (EXPANDED header) | Switch snapshot; right-click: store here |
| **MORPH** | Drag between A and B: every setting blends |
| **GENERATE** | A new piece; hold: swap with the one before |

## Window, files and the DAW

| Do this | And this happens |
|---|---|
| Click the Tessera mark | The menu: SKIN, INK, MODE, SIZE, FM-1 USB, KEYS, LISTEN, TRACK, OUTPUTS, MANUAL |
| Drag the window's corner | Any size from 75% |
| **Ctrl+O**, **Ctrl+S** | OPEN, SAVE (standalone; the DAW's in a DAW) |
| MIDI button | Click: saves the clip; drag: onto a DAW track |
| Right-click a button or key | Latches it (GLO + a key with one mouse) |
| Program Change 0 / 1 / 2 | CHAIN to section A / B / C at the next phrase |
| Program Change 8 to 15 | Every track to pattern bank 1 to 8 |
| **Space** (standalone) | PLAY / STOP |
